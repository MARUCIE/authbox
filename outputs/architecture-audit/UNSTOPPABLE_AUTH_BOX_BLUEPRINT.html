Unstoppable 的核心教训

  • 账户是牢笼，密钥才是自由。 账户意味着你必须请求许可才能访问自己的数据；密钥意味着你天然拥有访问权，无需向任何人证明。
  • 值(Value)可以存在于任何场所(Place)，场所消失了值还在。 你的密码、身份凭证、AI Agent 配置 -- 这些是"值"。服务器、云盘、手机 -- 这些是"场所"。前者是本质，后者是容器。
  • 系统的简单性不在于它做的事少，而在于它的概念少且彼此正交。 正交意味着改变一个维度不会影响另一个维度。身份、存储、同步、AI 必须彼此独立。
03 五条 Complection 解辫

Hickey 将"complection"定义为将本不相关的概念编织在一起。以下是他在 Auth Box 当前架构中发现的五条编辫，以及对应的解法。符号 ⊗ 表示不当耦合。

1
身份(email) ⊗ 保险库访问
解: 种子词是唯一访问凭证，email 降级为可选的便利层通知通道。删除 email 不影响任何核心功能。
2
同步 ⊗ 存储 ⊗ 认证
解: 三者拆开，各自独立可替换。存储是本地文件，同步是可选传输，认证是本地密钥签名。任何一个出问题，其余两个完全不受影响。
3
在线状态 ⊗ 可用性
解: 本地优先，离线完全可用。在线是增强，不是前提。断网、断云、断服务器 -- 保险库照样打开，密码照样用。
4
AI 网关 ⊗ 密码存储
解: 本地签发委托密钥，AI 网关是可选的能力加速器。Agent 权限由用户本地签发和撤销，网关只是中继，不持有任何密钥。
5
账户生命周期 ⊗ 数据生命周期
解: 数据属于用户，与账户无关。注销账户 = 停止使用我们的同步服务。你的保险库、你的密钥、你的一切，永远在你手上。
04 三层架构蓝图

关键原则: 从 Layer 1 开始建 (SIMPLE)，向上叠加 (EASY)。绝不反过来。每一层都可以独立存在，上层的移除不影响下层。

Layer 3: CONVENIENCE 可选
email 通知 / 云同步 / 忘记密码找回 / AI Agent 云端增强能力
Layer 2: SYNC 可选，可替换
CRDT 合并引擎 / 传输通道: 服务端 relay | P2P | WebDAV | 手动导入导出
Layer 1: CORE 不可阻挡，必须
本地加密保险库 / 种子短语 → HD 密钥派生 / 离线完全可用
Agent 委托密钥 (本地签发) / 公开加密格式规范 (任何人可实现解密工具)
05 HD 密钥派生体系

以 BIP-39 助记词为根，通过分层确定性(HD)派生，一颗种子生成所有密钥。每个用途独立路径，互不影响，可单独撤销。

seed phrase (BIP-39, 24 words) → master key (Argon2id + HKDF) → m/auth_box'/vault'/0' 保管库主加密密钥 → m/auth_box'/sync'/0' 同步加密密钥 → m/auth_box'/agent'/0' Agent 委托根密钥 → m/auth_box'/agent'/1' Agent A 子密钥 (可单独撤销) → m/auth_box'/derive'/0'/<site_index> 确定性派生密码 (无需存储!)
最激进的创新: 确定性密码派生。 seed + 网站名 + 计数器 → 密码。Vault 里可以什么都没有。即使保险库被清空，只要种子词还在，所有密码都能重新计算出来。这不是恢复，这是重新推导 -- 数学上的确定性保证。
06 优雅降级谱系

真正的反脆弱不是"不会出问题"，而是"出了问题之后会怎样"。以下是从全功能到最极端场景的五级降级路径，每一级都有明确的能力边界。

降级等级 触发场景 可用功能 恢复时间
Level 0 全在线，所有服务正常 全部功能: 同步、AI Agent 云端增强、跨设备、实时通知 N/A
Level 1 服务器下线 / 网络中断 本地 Vault 完整可用 + 确定性密码派生 + 本地 AI 推理 0 秒
Level 2 公司倒闭 / 服务永久终止 Vault 永久可用。公开加密格式，任何人可实现兼容解密工具 0 秒
Level 3 设备丢失 / 损坏 新设备 + 种子短语 → 完整恢复所有密钥和确定性密码 < 5 分钟
Level 4 一切丢失，仅剩纸上种子词 种子短语 → 确定性密码重建。无需 Vault 文件，纯数学推导 < 10 分钟

注意: 每一级降级都保证数据安全性不降低。降低的只是便利性，不是安全性。

不可能三角分析 (Meadows)

传统观点认为"安全性 / 便利性 / 去中心化"三者不可兼得。Meadows 的系统思维揭示: 这不是真正的不可能三角 -- 三个目标实际存在于不同的系统层次。

韧性 / 安全
Layer 1 解决
状态架构层 -- 密钥在用户手中
便利性
Layer 2-3 解决
UX 和同步层 -- 可选叠加
AI 能力
有限授权解决
受限代理 -- 不是全能代理

关键洞察: 当你把三个目标放在同一层试图同时优化时，才会出现三角矛盾。把它们放在各自正确的层次上，矛盾消失。
