### ai --help
AI Tools - Unified CLI Entry Point

USAGE:
  ai [COMMAND] [OPTIONS]

COMMANDS:
  (none)              Start interactive menu
  sop                 SOP execution engine (59 SOPs)
    list              List all SOPs (--phase PLAN/BUILD/TEST/...)
    run <id>          Start SOP run (e.g., ai sop run 1.1)
    status [run_id]   Show run status or list all runs
    step <run> <n>    Update step (done/failed/skipped)
    complete <run>    Complete a run
    discover "text"   Find best SOP for a task
    map               Show SOP <-> Skill mapping

  find-skill, fs      Skill discovery & installation (agentskills.io)
    search "query"    Search GitHub for skill repos
    list [repo]       List installed or repo skills
    install <repo>    Install skills from a repo
    discover "task"   Find matching skills for a task

  workflow, wf        LangGraph workflow commands
    run <prompt>      Execute a workflow
    visualize         Show workflow graph
    interactive       Start REPL mode

  wf15                15-step multi-project pipeline
    run               Execute pipeline
    init              Initialize local config

  skills              Skill management
    list              List available skills
    run <skill>       Run a skill

  agents              Agent management
    list              List available agents
    --json            Output as JSON

  api                 AI model API commands
