## 关键词策略（中文为主，英文化补充）

| Cluster | 主关键词 | 次关键词 | 落地页 |
|---|---|---|---|
| C1 授权治理 | API 授权管理平台 | API key 生命周期管理、授权轮换 | `/product` |
| C2 安全运维 | 凭据轮换审计 | 凭据吊销、密钥治理 | `/features/credential-lifecycle` |

## SEO 执行优先级
1. 先上线 C1/C3/C4 对应页面（高意图词）。
2. 再上线 compare 页与 docs 内链。
3. 建立每月内容节奏：案例/合规更新/版本更新。
