# Product Hunt Launch Copy

## Tagline (60 chars max)
The password manager that works even if we disappear.

## Description (260 chars)
Auth Box uses BIP-39 seed phrases (same as Bitcoin wallets) to encrypt your passwords. No server dependency. Import from 13 sources. Manage 70+ AI API keys. Give AI agents controlled credential access via MCP protocol. Zero-knowledge. MIT licensed.

## First Comment (by Maker)
Hey Product Hunt! I'm Maurice, and I built Auth Box because I got tired of trusting corporations with my passwords.

The insight: if a 24-word seed phrase can secure millions in Bitcoin, why not your passwords?

Auth Box derives all encryption keys from a single seed phrase. If our servers disappear tomorrow, you still have everything. Just your 24 words.

What excites me most is the AI credential gateway. AI agents need API keys to work, but managing 50+ keys across projects is painful. Auth Box lets you:
- Drag-drop a .env file to auto-import 70+ provider types
- One-click verify if keys are still valid
- Give AI agents controlled access with policy gates

Built with Go, Next.js 15, and real SRP-6a authentication. 131 automated tests. MIT licensed.

Would love your feedback!
