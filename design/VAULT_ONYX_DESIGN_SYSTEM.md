## Core Rules

### 1. No-Line Rule
Do NOT use 1px solid borders. Use background color shifts for structure.

### 2. Ghost Border
If border is absolutely needed (a11y): `outline_variant` (#464553) at 20% opacity.

### 3. Glass & Gradient
- Hero CTAs: linear-gradient from `primary` to `primary_container` at 135deg
- Modals: `surface_bright` at 60% opacity + 20px backdrop-blur

### 4. Tonal Layering
Depth = stacking surface-container tiers. No box-shadow abuse.

### 5. Ambient Shadows
- Blur: 40-80px
- Opacity: 4-8%
- Color: Tinted indigo (never pure black)

## Component Specs

### Buttons
- Primary: Gradient fill, `on_primary` text, roundness `md` (6px)
- Secondary: `surface_container_highest` + Ghost Border
- Hover: Brightness increase or tier shift

### Inputs
- Base: `surface_container_highest`, no border
- Focus: 2px Ghost Border with `primary_fixed` at 40%
- Validation: Emerald (secure) / Amber (warning) / Red (terminal error only)

### Cards
- No divider lines
- Spacing scale: `spacing-8` to `spacing-12` between blocks
- Background color shift for nesting

### Security Components
- Pulse Indicator: Emerald dot with 4px glow (active session)
- Auth Code Inputs: `display-sm` Space Grotesk in individual `surface_container_highest` boxes
